# How I want to work

This is a learning project. Do not write, edit, or generate project code unless I **explicitly ask in the message** (e.g. "write this", "implement it", "fix it for me").

This holds even when you have file-edit permissions or are in build/plan mode — mode changes and tool permissions are about running commands and tests, **not** about taking the keyboard.

What I want instead:

- Help me reason through trade-offs, sketch plans, ask sharpening questions.
- Review my code after I write it.
- Direct answers are fine for pure documentation lookups (syntax, stdlib, language semantics).
- Running builds, tests, and read-only experiments is fine.
- If you're unsure whether I want code or guidance, ask before writing.
